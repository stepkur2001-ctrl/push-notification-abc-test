# Итоговый отчёт: A/B/C-тест пуш-уведомлений

## Контекст

Тестировали 3 варианта текста пуш-уведомления (A, B, C). Задача — понять, 
какой вариант даёт наибольший open rate (долю пользователей, открывших 
уведомление).

## Дизайн эксперимента

- Метрика успеха: open rate (доля открывших уведомление)
- Размер выборки: 1000 пользователей на группу (3000 всего)
- SRM-проверка: пройдена

## Гипотезы

**ANOVA:**
H0: μ_A = μ_B = μ_C (open rate одинаковый во всех трёх группах)
H1: хотя бы одна пара групп отличается

**Post-hoc (попарные сравнения):**
Для каждой пары i, j: H0: p_i = p_j, H1: p_i ≠ p_j

## Результаты

| Группа | Open rate |
|---|---|
| A | ~20% |
| B | ~25% |
| C | ~35% |

**ANOVA:** F набл = 29.82, F_крит(2, 2997) ≈ 3.00 → F набл >> F крит, 
p-value практически равно нулю.

Вывод: p-value < 0.05 → отвергаем H0. Между группами есть статистически 
значимые различия в open rate.

## Post-hoc анализ (поправка Бонферрони, α_скорр = 0.05/3 ≈ 0.0167)

| Пара | p-value | Значимо? |
|---|---|---|
| A vs B | 0.004427 | Да |
| A vs C | ≈3.2×10⁻¹⁴ | Да (очень сильно) |
| B vs C | 0.00000242 | Да |

Все три пары статистически значимо отличаются друг от друга даже после 
строгой поправки на множественные сравнения. Наблюдается чёткая иерархия: 
C > B > A. Особенно выражено отличие C от A — вариант C кардинально 
превосходит остальные.

## Рекомендация

Внедрить вариант уведомления C — показал значимо более высокий open rate 
по сравнению с обоими остальными вариантами.

## Ограничения

- Данные синтетические (демонстрационный проект)
- Не проверялся возможный эффект новизны формулировки текста
- Не учтена гетерогенность по сегментам пользователей (платформа, время суток отправки)
